# Nev Launcher 隐私政策

**项目主体：** ZalithLauncher2（简称 **ZL2**）  
**开发团队：** ZalithTeam（以下简称 **我们**）  
**版本：** 1.0  
**生效及最后更新日期：** 2026 年 10 月 30 日

## 一、引言

本政策说明你在 Android 设备上使用 ZL2 时，信息如何被存储、处理和传输。本政策适用于官方 ZL2 版本及项目运营的信息服务，不适用于修改版、非官方网站或第三方服务；后者适用其各自规则。

ZL2 主要在设备本地运行。当前版本不包含由 ZalithTeam 运营的用户账户系统、广告 SDK 或行为分析 SDK，核心本地功能不要求你向我们注册。

但 ZL2 是联网启动器。账户认证、搜索、下载、更新、多人联机、可选日志上传及外部网页均需要与第三方服务通信。即使信息没有发送到 ZalithTeam 服务器，相关服务提供方仍可能收到你的 IP 地址和请求元数据。

首次启动或使用 ZL2 前，你必须完整阅读并明确同意本政策和《ZalithLauncher2 用户协议》两份文件。若你拒绝或不同意其中任何一份文件，启动器将不允许你进入或继续使用 ZL2 及其任何功能。

此后如任一份文件发生更改，启动器将在你下一次打开应用时，重新弹出并展示两份文件更新后的完整内容，要求你重新明确同意。若你拒绝或不同意更新后的任一份文件，启动器将不允许你使用 ZL2。

## 二、在设备上存储和处理的信息

根据你使用的功能，ZL2 可能在本地存储或处理以下信息：

### 2.1 设置与应用数据

- 启动器偏好设置、语言相关设置、外观、控制方式、下载来源及功能选项；
- 游戏目录路径、已安装版本信息、Java 运行环境、渲染器及组件配置；
- 控制布局、导入文件、已下载资源、缓存、皮肤、披风及导出文件；以及
- 你创建、导入或下载的游戏存档、日志、模组、整合包、资源包、光影及其他文件。

### 2.2 账户信息

对于 Microsoft/Minecraft 账户，ZL2 可能在本地保存玩家名、角色 UUID、Xbox 用户标识、访问令牌、刷新令牌、令牌到期时间、账户类型以及下载的皮肤或披风。

对于你选择的第三方认证服务器，ZL2 可能在本地保存服务器地址、账户名或邮箱、密码、访问令牌、客户端令牌、角色 UUID 及相关账户数据。当前账户实现会保留第三方认证服务器的密码，以便进行账户认证。请仅对可信服务器使用该功能，并妥善保护设备访问权限。

Microsoft 设备代码授权通过 Microsoft 服务完成。ZL2 不要求你输入，也不会接收你的 Microsoft 账户密码。Microsoft 可能依其隐私政策请求和处理其他信息。

### 2.3 诊断信息与日志

ZL2 及所启动的游戏可能生成本地启动器日志、原生日志、崩溃报告、游戏日志及 Terracotta 联机日志，其中可能包含：

- 应用和游戏版本、Android 版本、设备型号、CPU 架构、图形及运行环境信息；
- 时间戳、错误、堆栈轨迹、性能或连接详情；
- 玩家名、角色标识、文件路径、服务器地址、房间码、网络地址、命令或配置详情；以及
- Minecraft、模组、运行环境、插件或操作系统写入日志的其他信息。

除非你主动上传、导出或分享，日志仅保留在本地。Android Logcat 和诊断功能还可能使操作系统，或具有相应设备访问权限的人员和工具，获得部分信息。

### 2.4 麦克风与传感器信息

麦克风测试在本地读取音频采样，用于计算并显示相对音量。ZL2 的麦克风测试不会保存音频录音，也不会将音频采样传输给我们。

陀螺仪或运动传感器输入、触摸输入及振动功能在设备上处理，用于提供游戏控制。ZL2 不会在这些本地控制功能中上传上述传感器输入。

## 三、联网功能涉及的信息传输

具体信息取决于你的操作和所选服务。网络服务提供方通常会收到你的 IP 地址、请求网址、请求时间及标准连接或 HTTP 元数据。我们不控制其服务器日志或保存期限。

### 3.1 Microsoft、Xbox 与 Minecraft 服务

当你添加、刷新、验证或使用 Microsoft 账户时，ZL2 会与 Microsoft、Xbox Live 及 Minecraft/Mojang 服务通信。请求可能包含设备代码、OAuth 令牌、Xbox 令牌、玩家角色标识、游戏所有权查询及皮肤或披风请求。相关服务依其条款和隐私政策处理账户信息。

当你进行在线游戏时，Minecraft、已安装模组及所选游戏服务器还可能独立交换账户、游戏过程、网络及设备信息。ZL2 不控制这些独立通信。

### 3.2 第三方认证服务器

选择第三方认证服务器后，ZL2 会将你输入的账户名或邮箱及密码发送至该服务器进行认证，并按需发送或验证访问令牌、获取玩家角色、皮肤或披风。

服务器运营方而非 ZalithTeam 决定这些信息的使用方式和保存期限。ZL2 支持自定义服务器地址，且你配置或获取的部分内容可能使用未加密的 HTTP。请尽可能使用可信的 HTTPS 服务。

### 3.3 游戏、运行环境与内容下载

当你浏览版本、搜索内容、安装游戏或加载器、检查模组更新或下载资源时，ZL2 可能向相应来源发送版本号、游戏或加载器选项、项目或文件标识、搜索词、已安装模组标识和版本、架构信息及下载请求。

来源可能包括：

- Mojang/Minecraft 分发服务；
- Forge、NeoForge、Fabric、Quilt、Legacy Fabric、OptiFine、Maven 仓库及其他运行环境或依赖库来源；
- Modrinth、CurseForge 及其内容分发服务；
- BMCLAPI、MCIM Mirror、腾讯 Maven 镜像、GT New Horizons 仓库及其他镜像或社区来源；以及
- 你选择的自定义网址和来源，或你导入的内容中指定的来源。

第三方内容在下载或导入后可能自行联网，其行为不受我们对 ZL2 本身所作说明的约束。

### 3.4 更新检查与项目信息

ZL2 检查启动器更新或获取赞助商等项目资料时，可能访问 GitHub API 和内容服务。在中文语言环境下，如 GitHub 请求失败，更新获取可能回退至 `repo.miawa.cn`。

更新检查会向服务方暴露所请求的项目资源及标准网络元数据；当前应用版本在本地与获取的发布信息进行比较。选择更新、插件、网盘链接或外部下载时，将打开或联系相应第三方服务。

语言、区域和时区设置可在本地用于选择翻译、地区镜像或备用来源。ZL2 不会为此请求精确位置权限。

### 3.5 可选日志上传

ZL2 不会自动向我们上传崩溃报告或日志。只有你明确选择上传并分享日志时，日志完整内容才会发送至相应上传服务：

- **mclo.gs**（`api.mclo.gs`）；或
- **logshare.cn**（`api.logshare.cn`），在本地被识别为中国大陆环境时可能先于 mclo.gs 尝试。

如首先尝试的服务失败，ZL2 可能改用上述其他服务重试。上传后的日志可能生成可供他人访问的链接，请将其视为已向上传服务及获得链接者共享的信息。

上传前请检查并尽可能移除敏感信息。上传服务自身的访问、保存和删除规则适用，我们可能无法代你从第三方服务删除日志。

### 3.6 Terracotta/EasyTier 多人联机

使用多人联机功能时，除非你配置自定义节点，ZL2 会从 `terracotta.glavo.site` 获取节点列表。为创建或加入房间，Terracotta/EasyTier、所选或自定义节点、中继及其他参与者可能处理：

- 房间码或邀请码、玩家名；
- 机器或对端标识、IP 地址、端口、连接状态及路由元数据；
- 节点地址及诊断日志；以及
- 建立和维持多人联机连接所需的网络数据包。

实际数据路径取决于涉及的节点和参与者。不得利用该功能从事违法活动，也不应认为其能够提供匿名性。不再需要时，请停止连接。

### 3.7 网页、Cookie 与外部链接

ZL2 可在内置 WebView 中展示项目页面或第三方内容，也可通过其他应用打开。内置 WebView 在页面使用期间启用 JavaScript 和 DOM 存储，并允许 Cookie（包括第三方 Cookie）。所访问网站因此可能存储标识符，并依其政策收集浏览及设备信息。

离开 ZL2 内置 WebView 页面时，ZL2 会销毁 WebView、清除历史记录、删除应用管理的 WebView 缓存目录，并请求移除 WebView Cookie。这不会删除网站已经收集的信息，也不会删除外部浏览器中的数据。

ZL2 不会在这些页面中添加自己的广告或跟踪 Cookie。

### 3.8 DNS 回退

ZL2 优先使用操作系统 DNS。系统 DNS 解析失败时，可能通过 DNS over HTTPS 将待解析域名发送至 Cloudflare、Google Public DNS 或 AliDNS。成功的回退解析结果在内存中最多缓存 10 分钟。上述 DNS 服务方会依其政策收到被查询域名及标准网络元数据。

## 四、Android 权限与设备功能

相关权限用于以下目的：

| 权限或功能 | 用途 |
|---|---|
| 网络与网络状态访问 | 账户认证、搜索、下载、更新、联机、网页及连接状态检查 |
| 外部/共享存储，包括受支持 Android 版本上的所有文件访问 | 管理游戏目录、存档、模组、运行环境、导入和导出文件及你选择的其他内容 |
| 麦克风 | 为可选麦克风测试计算实时音量；ZL2 不利用该权限上传语音录音 |
| 通知与前台服务 | 显示任务、游戏、运行环境及联机状态，维持你请求的后台工作 |
| VPN 服务 | 经 Android 授权后建立 Terracotta/EasyTier 联机隧道 |
| 唤醒锁 | 在需要时维持相关游戏或后台任务运行 |
| 振动与运动传感器 | 提供游戏控制反馈及可选运动控制 |

拒绝某项权限可能限制对应功能，但不影响无关的本地功能。你可在 Android 设置中更改权限。广泛存储权限可能使你选择管理的文件面临风险，请谨慎使用，并仅处理可信内容。

## 五、信息的使用目的

ZL2 在本地并通过你请求的服务提供方使用信息，以：

- 认证账户并维持登录会话；
- 安装、配置、启动和管理 Minecraft 及相关内容；
- 提供搜索、下载、更新、文件管理、控制和多人联机功能；
- 显示状态、诊断错误并维护本地日志；
- 记住偏好设置和所选来源；以及
- 完成你主动请求的分享或上传操作。

当前 ZL2 应用不会利用你的本地账户凭据、存档、日志或文件建立广告画像、出售个人信息，或训练由 ZalithTeam 运营的画像系统。

## 六、信息的共享

我们不出售或出租你的个人信息。

在第三条所述情形下，信息主要因你使用需要与相应服务直接通信的功能而离开设备。对于你主动提交给我们的信息，例如问题报告或电子邮件，我们可能为回复、调查安全问题或维护项目的合理需要，向贡献者或服务提供方披露。

对于由我们持有的信息，如适用法律或有效法律程序要求，或为了保护用户、贡献者及公众的权利、安全，我们可能依法披露。

已经向第三方服务、日志接收者、联机参与者或外部网站披露的信息，同时受接收方规则约束，而非仅受本政策约束。

## 七、保存期限与删除

本地信息通常保留至你删除相关信息、移除对应账户、清除应用数据或卸载 ZL2，具体如下：

- 启动器日志默认保存 **7 天**，可设置为 **1 至 14 天**，旧日志会在日志系统初始化时清理。其他游戏、原生、崩溃或 Terracotta 日志可能适用不同的生命周期规则。
- 缓存可能保留至被替换、清除，或由 Android 或你删除。
- 共享或外部存储中的文件、导出内容及另行安装的游戏文件，可能在卸载后仍然保留。
- 从 ZL2 移除账户会删除其本地数据库条目及关联的本地皮肤文件，但不会撤销或删除账户服务方持有的数据。必要时请通过该服务方撤销会话。

ZL2 已启用 Android 备份和设备转移功能。根据设备及其设置，应用数据可能由操作系统复制到云备份服务或另一台设备。Google、设备制造商或其他备份服务方依其政策控制该处理过程。删除本地数据不一定会立即删除已有的系统备份。

第三方服务自行决定保存期限。如需删除服务端账户数据或已上传日志，请联系相应服务方。

## 八、信息安全

ZL2 依赖 Android 应用沙箱和本地存储控制，并针对支持的连接采用网络安全机制。但任何应用、设备、网络或存储方式都不可能绝对安全。

请使用屏幕锁保护设备，及时更新 Android 和 ZL2，避免使用不可信的修改版及认证服务器，不要分享令牌或未经检查的日志。若他人获得对应用数据、设备备份或已受破坏设备的充分访问权限，本地保存的第三方账户凭据可能泄露。

为兼容自定义及第三方来源，ZL2 允许明文网络流量。通过 HTTP 而非 HTTPS 发送的信息可能被截获或篡改，请优先选择可信的 HTTPS 来源。

## 九、你的选择与权利

你可以在 ZL2 或 Android 中：

- 查看并移除本地保存的账户；
- 更改下载来源、自定义认证服务器及功能设置；
- 根据 Android 版本和设备控制方式，撤销麦克风、存储、通知或 VPN 权限；
- 自主决定是否上传、导出或分享日志及其他文件；
- 清除应用数据、删除本地文件或卸载 ZL2；以及
- 通过设备或备份服务方设置关闭或管理系统备份。

根据所在司法辖区，你可能还享有访问、更正、删除、限制或反对处理个人信息、获取副本及撤回同意的权利。由于 ZL2 主要在本地保存信息且没有通用用户账户数据库，你可以直接在设备上行使其中许多选择。

对于 ZalithTeam 持有的信息，请通过下方方式联系我们。对于 Microsoft、自定义认证服务器、内容平台、日志上传服务、联机节点或其他服务方持有的信息，请直接向相应服务方提出请求。我们可能需要必要的信息核验请求，但请勿向我们发送密码或认证令牌。

## 十、儿童与未成年人

由于我们不提供 ZalithTeam 账户系统，ZL2 并非旨在通过此类账户收集儿童信息。但账户、在线游戏、多人联机和网页功能仍可能涉及个人信息及第三方服务。

未成年人应在父母或其他法定监护人同意、陪同和指导下使用 ZL2。监护人应关注账户设置、下载内容、日志分享、联机活动及第三方隐私政策。Microsoft、Mojang、相关平台和适用法律规定的年龄要求及监护人同意机制也必须遵守。

如你认为儿童不当地直接向我们提供了个人信息，请联系我们，以便我们依法评估和处理。

## 十一、跨境处理

ZL2 可能联系位于不同国家或地区的服务方及联机参与者。因此，你的 IP 地址、账户请求、下载、上传日志及联机数据可能在居住地之外被处理。不同司法辖区的隐私保护及政府访问规则可能不同。

对于依法需要额外保障且由 ZalithTeam 负责的跨境传输，我们将采取合理适当措施。第三方服务方仍须对其自身的传输机制和法律义务负责。

ZL2 功能、服务提供方或法律义务发生变化时，我们可能更新本政策。修订版将注明新的日期和版本号，并随 ZL2 或通过官方项目渠道提供。对于重大变更，我们会在可行情况下给予合理的额外通知。

本政策或《ZalithLauncher2 用户协议》发生任何更改后，启动器将在你下一次打开应用时，重新弹出并展示两份文件更新后的完整内容。你必须重新明确同意两份文件；若你拒绝或不同意更新后的任一份文件，启动器将不允许你使用 ZL2。
