# PetLib 模型契约

PetLib 通过运行时解析 glTF（GLB 容器或内嵌 .gltf）加载人物模型。
本文描述加载器接受的 glTF 子集与命名约定。满足本文的模型文件
即可被 PetLib 加载和渲染，包括日后通过自定义模型入口加载的模型。

## 容器

- **GLB**（推荐）：二进制容器，JSON chunk + BIN chunk。
- **内嵌 .gltf**：JSON + 单 buffer 的 data URI。

仅支持单 buffer。外部 .bin 引用不受支持。

## 坐标系与单位

- 右手坐标系，Y 向上，模型面向 −Z（与 glTF 标准一致）。
- 1 glTF 单位 = 16 模型像素（加载时自动换算）。
- 根节点层级中须包含一个 180°Y 旋转节点（如 blockbench_export），
  将模型从 glTF 基换入渲染基。

## 节点树

- 节点使用 TRS（不接受 matrix）。
- 网格节点命名以 `_Layer` 结尾的归入外层绘制序（半透明后绘）。
- 编辑辅助节点（无网格、不参与动画）会被遍历但不产生绘制。
- rig 工具链约定：骨架为真正的 Armature（模型禁蒙皮，但骨骼可导出为
  普通 TRS 节点），骨名与具名关节 1:1；作者在 Pose Mode 直接摆骨，
  键打在姿态骨上，导出为具名关节的动画通道。导出的模型文件不包含
  `CTL_` 节点与骨架对象。

## 具名关节（程序化姿态依赖）

以下名字的节点驱动程序化效果；缺失则跳过对应效果：

| 关节名 | 用途 |
|--------|------|
| Body | 躯干（行走摆动、攻击扭转、待机下沉） |
| Head | 头部（注视追踪、行走点头） |
| Left_Arm / Right_Arm | 左臂/右臂（行走摆动、攻击挥臂） |
| Left_Leg / Right_Leg | 左腿/右腿（行走迈步） |
| Cape | 披风（行走飘动、待机微摆） |

## 材质与纹理

- 玩家模型：材质名含 "cape"（不分大小写）→ 绑定披风纹理，其余绑定皮肤；
  运行时由用户皮肤/披风替换，glTF 内嵌贴图不使用。
- 道具模型（无皮肤绑定）：每个材质绑定 pbrMetallicRoughness.baseColorTexture
  指向的内嵌图片（GLB bufferView 或 data URI，PNG/JPEG），
  加载时报错缺纹理；API 可按材质名覆盖。
- 图片仅支持内嵌来源；外部 URI 引用在玩家模型上被忽略（皮肤替换），
  在道具模型上拒绝加载。

## 网格

- 三角形网格（mode 4），索引 u16/u32。
- 顶点属性：POSITION / NORMAL / TEXCOORD_0（均 f32）。
- 顶点 UV 需映射到 Minecraft 皮肤图集（64×64 布局）。
- 帽层网格（`_Layer` 后缀）可选；缺失时仅渲染基础层。

## 动画

- rotation / translation 通道，LINEAR 插值。
- 旋转为四元数 (x, y, z, w)，平移为 VEC3。
- 时间轴均匀网格（帧率恒定）或一般时间点均可。
- 插值器必须为 LINEAR（或省略）。

### 命名约定

| 动画名 | 用途 |
|--------|------|
| idle | 基础待机循环 |
| idle_sub_* | 随机待机子动画（每 8 秒随机播一个，不连续重复） |
| interact | 点击反应动画（截取前 0.5 秒） |

### 动画对象

加载时每个剪辑实例化为 Animation 对象（时间/速度/循环/权重），
可并行播放、按权重混合，重叠关节按权重合成。常规名由自动调度
（待机随机轮换、点击截断）驱动，手动对象与之并存。

## 场景与相机

- 场景世界单位 = glTF 单位（1 单位 = 1 方块 = 16 模型像素），Y 向上；
  实例位置 = 模型根原点落点，姿态为欧拉 pitch/yaw/roll（度），均匀缩放。
- 相机枚举双模式：正交（zoom = 屏宽覆盖的世界单位数）与
  透视（fov 为垂直视场角，度）；均为绕注视目标的轨道参数
  （方位角/仰角/距离）。默认机位等效旧固定机位。
- 光照与超采样为场景级；外层显隐为模型级；输出为透明底预乘 RGBA。
- 光栅化共享同一 z-buffer，逐像素记录实例 id，供像素级拾取。
- 透视模式带近平面裁剪（顶点越过相机平面的三角形被截断）。

## 皮肤映射

- 基础层网格的 UV 映射到 Minecraft 64×64 皮肤图集。
- 旧版 64×32 皮肤在加载时自动重排为 64×64 现代布局。
- 左肢像素由右肢镜像填充（仅基础层；外层区域保持透明）。

## 已知怪癖

- 部分导出器的面缠绕方向与法线属性可能不一致（本模型头部顶面
  即内向缠绕）。加载时自动统一缠绕方向为外向。
- wasm32 目标无时钟系统调用，待机调度使用固定种子兜底；
  宿主可通过 seed_idle 覆盖。
