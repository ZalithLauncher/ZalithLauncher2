# NusaLauncher brand assets

| File | Use |
|---|---|
| `nusa-icon.svg` | Monogram (NL), transparent background. Source for the app icon. |
| `nusa-logo.svg` | Horizontal wordmark, transparent. The white "LAUNCHER" text needs a dark background. |
| `nusa-icon-512.png` | 512 px monogram, transparent. |
| `banner.png` | 1280x640 banner for the README and social preview. |

## Colors

| Role | Value |
|---|---|
| App background | `#0E0E10` |
| Accent (gradient top) | `#FFC20D` |
| Accent (middle) | `#FF8A0A` |
| Accent (gradient bottom) | `#FF4412` |
| Wordmark white | `#F1F1F0` |

The Android launcher icon (`ZalithLauncher/src/main/res/drawable/ic_launcher_foreground.xml`)
is generated from `nusa-icon.svg`. Re-generate it if the SVG changes.
