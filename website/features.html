Features

Everything in the box

No locked tiers and nothing held back. This is the whole launcher.

Play

Your instances, in order

🏠

Unified Play hub

Recent worlds and your library sit on one screen, so getting back into a world is a single tap.

🧱

Instance management

Launch, edit, duplicate, delete and open the folder for any instance. Isolated game directories keep versions from colliding.

🎨

Instance icons

Give each instance a colour, a symbol or an emoji so a wall of modpacks stays readable.

📂

Instance groups

Sort modpacks, survival worlds and test builds into their own groups.

⚙️

Per-instance settings

Renderer, RAM, resolution, Java runtime and JVM arguments, set globally or overridden per version.

📦

Modpack import

Import a modpack the launcher did not download, straight from a file.

Discover

Find it, install it, play it

Search across several sources with a sequential fallback, so one platform having a bad day does not break your search.

🔍

Five content types

Modpacks, mods, resource packs, shaders and world saves, browsable from inside the launcher.

🧭

Filters that know Minecraft

A full version catalog from 26.3 back to 1.4.7, newest first, plus loader filters. Versions that show up in your results pin themselves to the top.

⭐

Favourites

Keep the packs you actually use one tap away instead of re-searching for them.

🎯

Auto-detection

Mirai reads a file's supported Minecraft versions and loaders, tells you what it found, and pre-checks the installed instances it fits.

🖼️

Rebuilt detail pages

A hero card and a screenshot rail directly beneath it, so you can see a shader pack before committing to the download.

⏳

Minimizable installs

Shrink the install dialog to a small floating button and keep using the launcher while a modpack unpacks.

Performance

Built for a phone, not a demo

Four tools that do the fiddly parts for you. All four remember what they chose.

⚡

1-Tap FPS Booster

One tap applies a full mobile FPS preset tuned for the device. Whatever it picks persists across restarts, so you never re-tune it.

🧮

JRE & GC auto-tuner

Picks the Java runtime and garbage collector combination for your hardware, then leaves it alone. Sensible defaults instead of a wall of flags.

🩺

Smart Crash Doctor

Reads a crash log and tells you what it thinks went wrong, in plain language, instead of leaving you with a stack trace.

🔧

Mod dependency resolver

Finds missing dependencies and version conflicts between installed mods and resolves them, rather than letting the game die on startup.

Honest note on performance Mirai does not publish FPS comparisons against other renderers, because those numbers depend on the phone, the mod load and the world. The tuning above is what it ships; the measuring is yours to do.

Accounts

Who you log in as

👤 Offline accounts

Create a local username and select it. The radio stays selected, the skin and cape stay equipped, and nothing leaves the device.

🌐 Microsoft login

Sign in with a Microsoft account that owns Java Edition, through the device-code flow.

🔑 Yggdrasil / auth servers

Log in against third-party authentication servers for the servers that run their own.

👕 Skins and capes

Equip both on an offline account and preview them on a 3D paper doll you can spin a full 360°.

In game

Controls and the things around them

🎮

Touch control editor

Move, resize and restyle every button, then save it as a custom layout you can switch between.

🕹️

Gamepad support

Mapped input with a dead-zone scale, cursor and camera sensitivity, and separate joystick modes.

📱

Gyroscope aiming

Optional gyro control with adjustable sensitivity, sample rate, smoothing and axis inversion.

🗂️

Built-in file manager

A full file manager for configs, mods, worlds and backups — with an editor, a trash screen and extraction — without leaving the launcher.

📜

Log viewer

Watch the game log live, or read it afterwards when something went wrong.

💬

Mirai Pill HUD

Quick in-game actions for worlds and screenshots, kept out of the way until you want them.

Look and feel

Make it yours

🌗

Material 3, dark and light

A modern interface that follows the system, or holds a theme you chose on purpose.

🎨

Accent control

Pick a palette style and a custom accent, or let the wallpaper choose one for you.

🖼️

20 built-in wallpapers

HD Minecraft wallpapers with a dim slider, a Solid Dark mode, and room for your own imports.

🌍

18 languages

Arabic, Chinese (Simplified and Traditional), Estonian, Filipino, Indonesian, Italian, Japanese, Korean, Portuguese, Russian, Spanish, Thai, Turkish, Uyghur, Vietnamese and more.

🪟

Landscape layouts

Dedicated landscape screens with animation, since that is how the game is actually played.

✨

Festival effects

Optional seasonal touches you can switch off if you would rather have the quiet version.
