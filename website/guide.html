Setup guide

From APK to playing

About ten minutes, most of it waiting for the first launch to unpack.

Before you start

  • Android 8.0 or newer. 4 GB of RAM is a realistic floor for a modern version; more is better.
  • Around 2 GB of free storage for the launcher runtime, plus whatever your Minecraft version and mods need.
  • Owning the game is on you. Mirai does not include Minecraft and does not give you an account. Use a Microsoft account that owns Java Edition, or an offline profile for single-player and LAN.

Steps

Getting set up

Download the right APK

Open the latest release and pick the file for your device. Nearly every modern phone is arm64-v8a. Choose all if you are unsure — it works everywhere and is simply larger.

Allow installs from that source

Android will refuse a sideloaded APK the first time. When prompted, allow your browser or file manager to install unknown apps, then install the file.

Let the first launch finish

Mirai unpacks its Java runtime and components on first start. This takes a few minutes and looks like it is doing nothing. It is not stuck — let it finish.

Add an account

Go to Settings → Accounts. For Microsoft, use the device-code flow: Mirai shows you a code and a page to enter it on. For an offline account, just type a username — you can equip a skin and cape on it afterwards.

Install a Minecraft version

From Library, create an instance and pick a version. Use Discover instead if you want a modpack — Mirai will install Minecraft and the loader together.

Press Play

Mirai picks a renderer for the version automatically. If the game fails to start, the first thing to try is a different renderer in Version settings → Renderer.

Tuning

The settings worth touching

Everything else has a sane default. These three are the ones that change how it feels.

🧩

Renderer

The single biggest lever. Leave it on automatic until something misbehaves; then try the next option for your version. See the lineup.

🧮

RAM

Set a global allocation, then raise it per instance for a heavy modpack. Allocating more than the phone can spare is worse than allocating too little.

📐

Resolution

Rendering below native resolution is the most reliable way to gain frames on a mid-range phone, and it is usually hard to notice on a small screen.

When it goes wrong

Quick checks

It closes immediately after Play Almost always the renderer. Open version settings and switch to a different one for your Minecraft version. On 1.16.5 or older that means LTW Legacy, GL4ES or vgpu; on 1.17+ try LTW or MobileGlues.
The game crashes the moment you join a world If you have Sodium, Embedium or Rubidium installed, update Mirai. Recent builds apply a chunk-backend fix to those mods' configs on every renderer, covering both existing configs and first-run defaults.
A modpack will not start Open the log viewer from the game screen. Mirai's crash reader will usually name the missing dependency, and you can add it through Discover without leaving the launcher.
Downloads stall at 0 B/s Mirai retries and falls back between sources, but a VPN or a restrictive network can still get in the way. Switching the download source in settings to a mirror often clears it.

Still stuck? The Discord server is where a device-specific problem gets answered fastest.
